# 股权分析系统功能设计

## 1. 建设目标

建设一个面向招采监管场景的股权分析系统，围绕“关系识别 → 风险研判 → 证据支撑 → 智能监管”的逻辑链路，对同一项目、同一标段、同一批供应商或指定企业之间的股权、人员、联系方式、地址、投标行为等关系进行自动识别、风险判断、图谱展示和成果输出。

系统重点解决三个问题：

- 发现关系：自动识别企业之间是否存在股权交叉、共同股东、共同实控人、交叉任职、共同联系方式、共同地址等关联关系。
- 判断风险：结合招采业务行为判断关联关系是否构成围串标、陪标、利益输送或供应商串通风险。
- 支撑监管：用关系图谱、证据链、风险报告和自动预警支撑监管人员快速核查和处置。

## 2. 总体功能架构

```text
股权分析系统
├─ 关系识别中心
│  ├─ 批量关联分析
│  ├─ 多层股权穿透
│  ├─ 多维关系识别
│  └─ 关联路径识别
├─ 风险研判中心
│  ├─ 风险规则识别
│  ├─ 关联聚类识别
│  ├─ 招采行为融合研判
│  ├─ 风险评分模型
│  └─ 隐性关系识别
├─ 证据支撑中心
│  ├─ 知识图谱展示
│  ├─ 关系路径展示
│  └─ 分析成果输出
└─ 智能监管中心
   ├─ 自动风险预警
   └─ AI辅助风险研判
```

## 3. 用户角色

| 角色 | 使用目标 | 典型操作 |
|---|---|---|
| 监管人员 | 快速发现项目中的围串标风险 | 选择项目、发起检测、查看风险、下载报告 |
| 业务审核人员 | 对具体风险进行复核 | 查看证据链、图谱路径、标记处理结果 |
| 系统管理员 | 配置规则、阈值和数据源 | 维护风险规则、评分权重、外部接口 |
| 领导/管理人员 | 掌握整体风险态势 | 查看看板、风险排行、区域/行业统计 |

## 4. 核心业务流程

### 4.1 项目批量分析流程

1. 用户选择项目或标段。
2. 系统自动加载该项目下的投标单位、招标人、招标代理机构、业主代表、评标专家等主体。
3. 系统补齐主体工商数据、股权数据、任职数据、联系方式、注册地址和历史招采行为。
4. 系统执行批量关联分析、多层股权穿透、多维关系识别和路径计算。
5. 系统执行风险规则、聚类分析、行为融合研判和评分模型。
6. 系统生成风险清单、关系图谱、证据链和分析报告。
7. 用户复核风险，进行处置、导出或重新检测。

### 4.2 指定企业分析流程

1. 用户输入或批量上传企业名称。
2. 系统进行企业名称自动补全和主体确认。
3. 用户设置分析层级、关系类型、持股比例阈值、是否包含历史关系。
4. 系统生成企业关系图谱、关联路径、疑似团伙和风险等级。
5. 用户导出图谱、路径明细和风险说明。

## 5. 功能设计

### 5.1 批量关联分析

功能定位：对同一项目、同一标段或用户上传的一批企业进行一键关联排查。

功能说明：

- 支持从项目中自动带出投标单位列表。
- 支持 Excel 批量导入企业或人员名单。
- 支持至少2家企业发起分析，建议支持1000家以内的批量排查。
- 自动识别企业之间的股权、任职、联系方式、注册地址等关联关系。
- 支持按项目、标段、批次保存分析结果。

关键页面：

- 新建分析任务
- 主体确认页
- 分析进度页
- 分析结果页

输出结果：

- 关联企业清单
- 关联关系矩阵
- 风险命中清单
- 可视化关系图谱

### 5.2 多层股权穿透

功能定位：识别企业向上股东、向下投资、最终受益人和共同实际控制人。

功能说明：

- 支持向上穿透股东结构，查看股东层级和最终受益人。
- 支持向下穿透对外投资，查看直接、间接投资对象。
- 支持配置穿透层级，默认2层，最大可配置到5层或更高。
- 支持按持股比例、企业状态、主体类型筛选。
- 支持识别共同股东、共同实控人、交叉持股、间接控股和循环持股。

关键配置：

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| 向上穿透层级 | 2 | 用于识别股东、实控人和共同上级股东 |
| 向下穿透层级 | 2 | 用于识别对外投资和下属企业 |
| 最小持股比例 | 10% | 低于阈值的弱关系默认不触发风险 |
| 是否包含历史股东 | 否 | 高级分析可开启 |

### 5.3 多维关系识别

功能定位：不只看股权，还要融合人员、联系方式、地址等多维信息。

识别维度：

| 维度 | 识别内容 | 典型风险 |
|---|---|---|
| 股权关系 | 共同股东、共同实控人、交叉持股 | 疑似同一控制、围标 |
| 人员关系 | 法人、董事、监事、高管交叉任职 | 利益关联、陪标 |
| 联系方式 | 电话、邮箱、联系人一致 | 供应商串通 |
| 地址关系 | 注册地址、办公地址一致或相近 | 空壳公司、关联经营 |
| 招采行为 | 共同投标、轮流中标、历史合作 | 围串标行为 |
| 历史关系 | 历史股东、历史任职、历史地址 | 隐性规避 |

输出要求：

- 每一类关系都要保留证据来源。
- 每一条风险都能追溯命中的字段和数据时间。

### 5.4 关联路径识别

功能定位：自动找出两个主体之间的关联路径，解释“为什么有关联”。

功能说明：

- 支持任意两个企业之间的最短路径分析。
- 支持展示多条路径，不只展示最短路径。
- 支持路径类型筛选：股权路径、任职路径、联系方式路径、地址路径、混合路径。
- 支持路径层级限制，避免图谱过大。
- 支持路径强度计算。

路径示例：

```text
投标单位A
→ 共同股东甲 持股30%
→ 投标单位B
```

```text
投标单位A
→ 高管张三 任职总经理
→ 关联企业C
→ 控股 投标单位B
```

### 5.5 风险规则识别

功能定位：把识别到的关系转化为可监管、可预警的风险结论。

规则示例：

| 规则编码 | 规则名称 | 命中条件 | 风险等级 |
|---|---|---|---|
| R001 | 投标单位共同控股股东 | 同一项目两个投标单位存在共同控股股东 | 高 |
| R002 | 投标单位共同股东 | 相同股东持股比例大于10% | 中 |
| R003 | 投标单位交叉任职 | 同一人员在两个投标单位担任关键职务 | 高 |
| R004 | 共同联系方式 | 多个投标单位电话或邮箱一致 | 中 |
| R005 | 共同注册地址 | 多个投标单位注册地址一致 | 中 |
| R006 | 招标方与投标方股权关联 | 招标人/代理与投标单位存在股权关系 | 高 |
| R007 | 历史任职关联 | 近一年存在关键人员历史任职关系 | 中 |

规则能力要求：

- 支持规则启停。
- 支持阈值配置。
- 支持风险等级配置。
- 支持命中说明模板。
- 支持按项目类型、采购方式、区域差异化配置。

### 5.6 关联聚类识别

功能定位：识别疑似关联企业团伙，而不是只判断两两关系。

功能说明：

- 将同一批企业按共同股东、共同人员、共同联系方式、共同地址进行聚类。
- 支持展示“疑似团伙”。
- 支持查看团伙内成员、共同节点、命中规则和风险强度。
- 支持团伙风险评分。

聚类结果示例：

| 团伙编号 | 成员数量 | 共同关系 | 风险等级 |
|---|---:|---|---|
| G001 | 5 | 共同股东、共同电话 | 高 |
| G002 | 3 | 共同注册地址 | 中 |

### 5.7 招采行为融合研判

功能定位：将工商关系与招采业务行为结合，避免只展示关系、不判断监管风险。

融合指标：

- 是否共同参与同一项目。
- 是否多次共同投标。
- 是否存在轮流中标。
- 是否存在投标报价规律异常。
- 是否存在历史合作关系。
- 是否存在同一联系人、同一文件制作机器码、同一保证金账户等业务异常。

研判方式：

- 工商关系命中后，再叠加招采行为特征提高风险等级。
- 招采行为异常但工商关系较弱时，标记为疑似风险。
- 支持按项目、供应商、时间区间查看历史行为。

### 5.8 风险评分模型

功能定位：将复杂关系转化为高、中、低风险等级。

评分维度：

| 维度 | 权重建议 | 说明 |
|---|---:|---|
| 关系类型 | 30% | 控股、任职、联系方式等风险强度不同 |
| 持股比例 | 20% | 持股比例越高，控制关系越强 |
| 路径长度 | 15% | 路径越短，关联越直接 |
| 主体角色 | 15% | 招标人、代理、投标人之间关系更敏感 |
| 招采行为 | 15% | 共同投标、轮流中标等增强风险 |
| 历史时间 | 5% | 越近的历史关系风险越高 |

风险等级：

| 分值 | 风险等级 | 处置建议 |
|---:|---|---|
| 80-100 | 高风险 | 重点核查，形成专报 |
| 60-79 | 中风险 | 人工复核，纳入关注 |
| 30-59 | 低风险 | 留痕备查 |
| 0-29 | 无明显风险 | 不预警或仅展示关系 |

### 5.9 隐性关系识别

功能定位：识别代持、协议控制、循环持股、亲属控制等非显性关系。

功能说明：

- 识别多层嵌套后的同一实控人。
- 识别循环持股和复杂交叉持股。
- 结合历史股东、历史任职、地址迁移、联系方式变化分析规避痕迹。
- 支持疑似代持模型，输出“疑似”而不是直接定性。
- AI 研判结果必须结合规则证据，不作为唯一判断依据。

### 5.10 知识图谱展示

功能定位：用图谱直观展示企业、人员、股权、任职和风险路径。

图谱节点：

- 企业
- 自然人
- 项目
- 标段
- 股东
- 高管
- 联系方式
- 地址

图谱边：

- 持股
- 投资
- 任职
- 法定代表人
- 联系方式相同
- 地址相同
- 共同投标
- 历史关联

交互能力：

- 搜索节点
- 展开/收起节点
- 高亮风险路径
- 按关系类型过滤
- 按风险等级过滤
- 查看节点详情
- 查看边证据
- 导出图谱图片

### 5.11 关系路径展示

功能定位：让监管人员清楚看到每个风险结论背后的路径。

展示内容：

- 起点主体
- 终点主体
- 中间节点
- 关系类型
- 持股比例或任职职务
- 路径层级
- 数据来源
- 命中规则

页面建议：

- 左侧展示风险清单。
- 中间展示关系路径图。
- 右侧展示路径详情和证据链。
- 支持切换“最短路径”“全部路径”“仅风险路径”。

### 5.12 分析成果输出

功能定位：将分析结果转化为监管可用材料。

输出类型：

- 风险清单 Excel
- 关系路径明细 Excel
- 股权图谱图片
- 项目风险报告 Word/PDF
- 证据链附件包
- 检测日志

报告内容：

- 项目基本信息
- 检测范围
- 风险概览
- 高风险主体
- 命中规则
- 关系图谱
- 证据链明细
- 处置建议

### 5.13 自动风险预警

功能定位：系统自动发现、推送和跟踪风险。

功能说明：

- 项目开标后自动触发检测。
- 新增投标单位后自动补充检测。
- 企业工商数据更新后自动重新检测。
- 命中高风险规则后推送预警。
- 支持预警状态流转：待核查、核查中、已确认、已排除、已归档。

预警信息：

- 风险等级
- 风险原因
- 涉及企业
- 命中规则
- 证据摘要
- 建议处置方式

### 5.14 AI辅助风险研判

功能定位：辅助解释复杂关系、生成摘要和处置建议。

功能说明：

- 根据图谱和证据链自动生成风险摘要。
- 对复杂路径进行自然语言解释。
- 根据历史案例推荐类似风险场景。
- 生成监管核查问题清单。
- 生成风险报告初稿。

边界要求：

- AI 只做辅助研判，不作为唯一判定依据。
- AI 输出必须引用规则命中和证据链。
- 关键风险等级仍以规则模型和人工复核为准。

### 5.15 标段风险监管工作台

功能定位：以标段为监管入口，将投标单位数量、问题数量、风险状态、风险详情、关系图谱和企业画像统一呈现在一个页面中，方便监管人员从“标段列表”快速进入“标段详情核查”。

功能说明：

- 支持展示标段风险列表，监管人员可按标段编号、标段名称和风险状态进行检索。
- 支持按风险状态筛选，包括全部风险、高风险、中风险、低风险和正常。
- 支持列表分页展示，避免标段数量较多时影响浏览效率。
- 支持重置查询条件，快速恢复默认列表状态。
- 支持从标段列表进入详情弹窗，查看当前标段的风险总览、单位风险详情、单位关系图谱和投标单位画像。
- 支持根据标段风险等级展示不同风险标识，帮助监管人员优先处理高风险标段。

列表字段：

| 字段 | 说明 |
|---|---|
| 序号 | 当前列表展示顺序 |
| 标段编号 | 标段唯一业务编号 |
| 标段名称 | 标段业务名称 |
| 投标单位家数 | 当前标段参与投标的单位数量 |
| 问题数量 | 当前标段命中的风险问题数量 |
| 风险状态 | 当前标段综合风险等级，包含高风险、中风险、低风险、正常 |
| 操作 | 查看标段详情 |

### 5.16 标段风险总览

功能定位：进入某一标段后，集中展示该标段的整体风险态势、系统诊断结论、风险分布和问题清单。

功能说明：

- 展示参与单位、问题单位家数、风险单位组数量、问题总数等核心指标。
- 展示股权审查结论卡，输出当前标段的综合审查结论和风险等级。
- 展示系统自动诊断结论，说明当前标段是否命中高风险红线、中风险警示或低风险线索。
- 展示详情分析思考与推理过程，说明系统从投标单位范围、企业档案、预警规则和风险等级等角度形成结论的过程。
- 展示 AI 深度挖掘风险情况，对高风险、中风险或低风险问题进行摘要说明。
- 展示风险数量分布，将风险归集到控股关系、人员关系、信息相同三类，并展示各类规则命中数量。
- 展示风险问题清单，列明问题类型、风险等级、涉及单位、关联路径、证据摘要和查看操作。

风险分布分类：

| 分类 | 包含规则 |
|---|---|
| 控股关系 | 直接控股、间接控股、参股关系、实际控制人、实际受益人 |
| 人员关系 | 主要人员审查、自然人股东审查、法人股东审查、法定代表人审查、管理关系审查 |
| 信息相同 | 年报信息审查、注册地址审查、注册电话审查、注册邮箱审查、专利信息审查、著作权审查、域名审查 |

### 5.17 单位风险详情矩阵

功能定位：按关联单位组展示命中的规则明细，让监管人员看到每组疑似关联单位触发了哪些风险规则。

功能说明：

- 支持按单位组汇总展示风险，每个单位组展示涉及单位、触发规则数量、综合风险状态和查看详情操作。
- 支持展开或折叠单位组下的规则明细。
- 支持按单位名称搜索风险单位组。
- 支持按规则分类筛选，分类包括股权关系维度、人员关系维度和主体联系维度。
- 支持清除搜索与筛选条件，恢复全部单位组排查记录。
- 支持查看单个单位组或单条规则的穿透图谱、联系方式详情等证据页面。

矩阵字段：

| 字段 | 说明 |
|---|---|
| 关联单位组 | 当前存在关联风险的投标单位组合 |
| 关联类型 | 命中的风险规则类型，如股权关系、人员关系、主体联系 |
| 具体情况 | 对规则命中原因的业务描述 |
| 风险状态 | 当前规则或单位组的风险等级 |
| 查看详情 | 查看关联拓扑、股权穿透或联系方式证据 |

### 5.18 股权与人员关联穿透详情

功能定位：对风险清单或单位风险矩阵中的单条问题进行钻取，展示当前问题涉及的单位、关系节点、风险节点和关联路径。

功能说明：

- 支持从风险问题清单、单位风险详情矩阵进入穿透详情。
- 对股权、人员类问题，展示合规穿透与关联拓扑图谱，聚焦当前查看对象及其关联风险。
- 当风险问题缺少可用图谱数据时，展示企业上层股东、当前投标单位、下游穿透路径等股权链条。
- 对联系方式、地址、邮箱等主体联系类问题，展示涉及投标单位的注册电话、注册邮箱和注册地址。
- 支持展示空状态说明，明确当前对象暂无可展示股权穿透数据或联系方式关联记录。

### 5.19 单位关系图谱

功能定位：在标段详情中嵌入单位关系图谱，用图形化方式展示当前标段投标单位之间的关系网络。

功能说明：

- 支持以当前标段编号和标段名称作为图谱查询上下文。
- 支持从标段详情页签打开当前标段的单位关系图谱。
- 支持从风险问题清单按问题类型和涉及单位跳转到聚焦后的图谱视图。
- 图谱应突出企业节点、风险节点、关联关系和重点风险路径，方便监管人员进行视觉核查。

### 5.20 投标单位画像与企业档案

功能定位：为标段内投标单位提供企业画像和企业档案查看能力，支撑监管人员对风险主体进行主体资质、工商信息、股东人员、知识产权等方面的核查。

功能说明：

- 支持在标段详情中打开投标单位画像页签，按当前标段上下文查看投标单位清单。
- 投标单位画像应支持按单位名称搜索和清除搜索条件。
- 投标单位清单展示单位名称、法定代表人、注册资本、统一社会信用代码、成立日期、电话、邮箱、地址和查看操作。
- 支持打开企业档案详情，查看企业基础信息、工商信息、股东及出资信息、主要人员、历史股东、历史主要人员、专利信息和作品著作权信息。
- 支持企业档案在详情页或全屏弹窗中展示，避免离开当前标段核查上下文。
- 支持企业档案内的数据下载入口，用于后续留痕或人工复核。


```json
{
  "projectId": "项目ID",
  "sectionId": "标段ID",
```

## 10. 建设难点与建议

| 难点 | 说明 | 建议 |
|---|---|---|
| 外部数据依赖 | 股权、任职、联系方式数据需要外部工商数据支撑 | 接入稳定数据源，建立本地缓存 |
| 批量计算性能 | 大量企业穿透分析计算量大 | 使用异步任务、图数据库和结果缓存 |
| 风险规则准确性 | 规则过严会误报，过松会漏报 | 支持阈值配置，并通过历史案例校准 |
| 图谱展示复杂 | 节点过多时图谱难以阅读 | 支持分层展示、路径过滤和风险高亮 |
| AI可信度 | AI可能生成不准确结论 | AI只做解释和辅助，最终以规则证据为准 |

## 11. 验收标准

- 能对同一标段投标单位进行批量关联分析。
- 能识别共同股东、共同实控人、股权交叉、交叉任职等核心风险。
- 能展示风险清单、风险等级、命中规则和证据链。
- 能展示企业关系图谱和关联路径。
- 能导出分析结果和风险报告。
- 高风险结论必须可解释、可追溯、可复核。
