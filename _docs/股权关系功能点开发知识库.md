## 4. 通用检测规则

### 4.1 股权交叉检测规则

功能描述：检测两个或多个主体之间是否存在直接或间接股权交叉关系，识别潜在围标串标、利益输送或控制关系风险。

功能逻辑：

1. 获取参与同一项目或同一标段的主体清单。
2. 拉取各主体股东、对外投资、历史股东和疑似实际控制人信息。
3. 对主体两两比对，识别直接股东重合。
4. 对股权链路进行穿透，默认穿透2层；具备数据条件时可扩展至3层或更多层。
5. 检测相同股东持股比例是否超过阈值，截图中阈值为相同股东持股比例大于10%。
6. 识别间接持股、共同控制、共同上级股东、互相参股等关系。
7. 生成风险结论、风险等级、证据链和股权交叉关系图。

建议风险等级：

| 风险等级 | 判定条件 |
|---|---|
| 高 | 主体之间存在直接控股、共同控股股东、同一实际控制人，或相同股东持股比例大于30%。 |
| 中 | 主体之间存在相同股东且持股比例大于10%，或2层穿透后发现间接控制关系。 |
| 低 | 主体之间存在少量参股、历史股东重合或弱关联关系。 |

### 4.2 高管交叉任职检测规则

功能描述：检测主体之间是否存在董事长、总经理、财务负责人等高管交叉任职或历史任职关系，识别潜在利益关联风险。

功能逻辑：

1. 获取各主体的董事长、总经理、财务负责人、法定代表人、负责人、董事、监事、高级管理人员名单。
2. 对人员姓名和身份证号进行标准化处理。
3. 优先使用身份证号或人员唯一ID匹配；缺失时使用姓名、任职主体、历史记录进行辅助匹配。
4. 两两比对高管姓名、证件号和任职记录。
5. 检查高管在其他主体，特别是投标单位、招标方、招标代理机构、专家单位、回避单位中的任职情况。
6. 检查过去1年的历史任职记录。
7. 生成任职交叉风险、证据链和任职关系图谱。

建议风险等级：

| 风险等级 | 判定条件 |
|---|---|
| 高 | 同一自然人同时在两个风险主体中担任法定代表人、董事长、总经理、财务负责人等关键职务。 |
| 中 | 同一自然人当前在两个主体中交叉任职，但职务非关键岗位；或过去1年内存在关键岗位历史任职。 |
| 低 | 仅存在较早历史任职、姓名疑似匹配或非关键岗位弱关联。 |

### 4.3 关联主体关系可视化规则

功能描述：对所有命中的股权关系、任职关系、历史关系进行图谱化展示，支持按主体搜索、按关系类型过滤、按风险等级高亮。

功能逻辑：

1. 以项目或标段为入口加载所有检测主体。
2. 将企业、自然人、项目、标段作为节点。
3. 将股权、投资、任职、历史任职、回避、专家所属单位等作为边。
4. 支持搜索主体名称、统一社会信用代码、人员姓名。
5. 支持按关系层级、风险等级、主体类型过滤。
6. 支持点击节点查看主体详情、点击边查看证据链。
7. 对命中风险的节点和边进行醒目标识。

## 5. 投标单位风险识别

### 5.1 投标单位间股权交叉分析

知识条目ID：equity_bidder_bidder_cross_analysis

功能描述：检测同一项目中多个投标单位之间是否存在直接或间接的股权交叉关系，识别潜在围标串标行为，生成股权交叉关系图。

功能逻辑：

1. 获取同一项目或同一标段下全部投标单位。
2. 对投标单位两两进行股权交叉检测。
3. 检查直接股东是否重合，重点判断相同股东持股比例是否大于10%。
4. 穿透两层股权结构，识别间接持股、共同上级股东、疑似同一控制人。
5. 输出风险主体、命中规则、持股路径、持股比例和风险等级。
6. 生成投标单位间股权交叉关系图。

输入数据：项目编号、标段编号、投标单位列表、股东信息、对外投资信息、股权穿透数据。

输出结果：投标单位间股权交叉风险清单、风险等级、证据链、关系图谱。

### 5.2 投标单位与招标方股权关联检测

知识条目ID：equity_bidder_tenderer_cross_check

功能描述：检测投标单位与招标人、招标代理机构之间是否存在股权或任职关联关系，对主体关系可视化展示，并自动识别、预警风险问题。

功能逻辑：

1. 获取投标单位、招标人、招标代理机构主体信息。
2. 检查投标单位股东与招标方股东的交叉情况。
3. 检测投标单位高管与招标方高管的交叉任职。
4. 穿透2层股权结构，识别间接控制关系。
5. 计算关联强度和风险等级。
6. 输出投标单位与招标方之间的股权、任职、控制关系。

输入数据：投标单位信息、招标人信息、招标代理机构信息、股东信息、高管信息、股权穿透数据。

输出结果：投标单位与招标方关联风险清单、关系图谱、风险预警。

### 5.3 投标单位间高管交叉任职检测

知识条目ID：equity_bidder_bidder_executive_overlap_check

功能描述：检测投标单位之间是否存在高管交叉任职的异常情况，对主体关系可视化展示，并自动识别、预警风险问题。

功能逻辑：

1. 提取各投标单位的董事长、总经理、财务负责人、法定代表人等高管信息。
2. 两两比对高管姓名和身份证号。
3. 识别当前交叉任职记录。
4. 检查历史交叉任职记录，重点关注过去1年。
5. 输出交叉任职人员、任职主体、职务、任职时间和风险等级。

输入数据：投标单位列表、高管人员信息、历史任职信息。

输出结果：投标单位间高管交叉任职风险清单、证据链、任职关系图谱。

### 5.4 投标单位与招标方高管交叉任职检测

知识条目ID：equity_bidder_tenderer_executive_overlap_check

功能描述：检测投标单位与招标方之间是否存在高管交叉任职的异常情况，对主体关系可视化展示，并自动识别、预警风险问题。

功能逻辑：

1. 提取投标单位、招标人、招标代理机构的董事长、总经理、财务负责人、法定代表人等高管信息。
2. 比对高管姓名、身份证号和人员唯一标识。
3. 识别投标单位高管是否在招标方任职。
4. 识别招标方高管是否在投标单位任职。
5. 检查过去1年的历史任职记录。
6. 输出异常任职关系和风险等级。

输入数据：投标单位高管信息、招标方高管信息、历史任职信息。

输出结果：投标单位与招标方高管交叉任职风险清单、证据链、任职关系图谱。

## 6. 施工标段中标合规性检测

### 6.1 施工标段投标主体资格核验

知识条目ID：equity_construction_bidder_qualification_check

功能描述：对非EPC项目施工标段的投标单位进行检测，检测投标单位是否是该项目的勘察和设计单位的中标单位。

功能逻辑：

1. 判断项目是否为非EPC项目。
2. 获取施工标段投标单位。
3. 获取该项目勘察标段、设计标段中标单位。
4. 比对施工标段投标单位是否与勘察单位或设计单位一致。
5. 命中时生成中标合规性风险。

输入数据：项目类型、施工标段投标单位、勘察标段中标单位、设计标段中标单位。

输出结果：主体资格核验结果、合规性风险提示。

### 6.2 施工标段投标主体股权分析

知识条目ID：equity_construction_bidder_owner_cross_analysis

功能描述：对非EPC项目施工标段的投标单位进行检测，检测该项目的勘察和设计单位的中标单位是否与投标单位存在直接或间接的股权交叉关系。

功能逻辑：

1. 获取同一项目施工标段的投标企业。
2. 获取勘察单位和设计单位的中标单位。
3. 对施工投标企业与勘察单位、设计单位进行股权交叉检测。
4. 检查直接股东是否重合，重点判断相同股东持股比例是否大于10%。
5. 穿透两层股权结构，识别间接持股关系。
6. 输出股权路径、命中规则和风险等级。

输入数据：施工标段投标单位、勘察单位、设计单位、股东信息、股权穿透数据。

输出结果：施工标段主体股权合规风险清单、证据链、关系图谱。

### 6.3 施工标段投标主体高管任职检测

知识条目ID：equity_construction_bidder_executive_overlap_check

功能描述：检测施工标段投标单位与勘察单位、设计单位之间是否存在高管交叉任职或历史任职关系。

功能逻辑：

1. 获取施工标段投标单位、勘察单位、设计单位的高管名单。
2. 比对董事长、总经理、财务负责人、法定代表人等关键人员。
3. 检查过去1年的历史任职记录。
4. 识别同一自然人在施工投标单位与勘察、设计单位之间的任职关联。
5. 输出异常关系和风险等级。

输入数据：施工标段投标单位高管信息、勘察单位高管信息、设计单位高管信息、历史任职信息。

输出结果：高管交叉任职风险清单、证据链、任职关系图谱。

## 7. 评标专家风险识别

5. 输出专家单位与投标单位的股权关联风险。

输入数据：评标专家信息、专家所在单位、投标单位列表、股权信息。

### 7.2 专家单位与投标单位任职交叉检测

4. 识别专家单位高管与投标单位之间的任职关联。
5. 输出交叉任职风险。

输入数据：专家单位高管信息、投标单位高管信息、历史任职信息。

输出结果：专家单位与投标单位任职交叉风险清单、证据链、关系图谱。

2. 获取专家历史填写的回避单位信息。
3. 检测专家单位与各投标单位的直接股东是否重合。
4. 穿透2层股权结构，识别间接关联。
5. 输出回避单位与投标单位的股权交叉风险。

输入数据：专家回避单位、历史回避单位、投标单位列表、股权信息。

输出结果：回避单位与投标单位股权交叉风险清单、证据链、关系图谱。

### 7.4 回避单位与投标单位任职交叉检测

知识条目ID：equity_avoidance_org_bidder_executive_overlap_check

功能描述：检测评标专家回避单位及历史填写的回避单位的高管与投标单位之间是否存在交叉任职或历史任职关系，对主体关系可视化展示，并自动识别、预警风险问题。

功能逻辑：

1. 提取专家回避单位的高管人员名单。
2. 检索高管在其他企业，特别是投标单位的任职情况。
3. 检查历史任职记录，重点关注过去1年。

## 16. 测试用例要点

### 16.1 股权交叉类

- 同一项目两个投标单位存在相同股东，持股比例大于10%，应命中风险。
- 两个投标单位不存在直接股东重合，但2层穿透后存在共同上级股东，应命中间接关联风险。
- 投标单位与招标人存在互相参股，应命中高风险。
- 股东名称相似但统一社会信用代码不同，应避免误判。

### 16.2 任职交叉类

- 同一自然人同时担任两个投标单位法定代表人，应命中高风险。
- 同一自然人在过去1年内从招标代理机构离职后进入投标单位，应命中历史任职风险。
- 仅姓名相同但证件号不同，应进入疑似风险或不命中，取决于数据完整度策略。

### 16.3 专家回避类

- 专家回避单位与投标单位存在共同股东，应命中风险。
- 专家历史回避单位与投标单位存在高管交叉任职，应命中风险。
- 专家所在单位与招标人存在股权关联，应命中专家与招标人关联风险。

### 16.4 施工标段合规类

- 非EPC项目施工标段投标单位等于勘察标段中标单位，应命中主体资格风险。
- 非EPC项目施工标段投标单位与设计标段中标单位存在共同股东，应命中股权合规风险。
- EPC项目不应套用非EPC施工标段主体资格规则。
